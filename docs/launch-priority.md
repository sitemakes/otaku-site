# OTAKU LIVE 公開・実装優先順位

## P0：正式公開前に必須

- 運営者名または屋号の確定
- 公開用問い合わせメールアドレスの確定
- 利用規約・プライバシーポリシーの確定
- 施行日・未成年者の利用条件の確定
- データ・ログ・通報記録の保存期間の確定
- 管理者の本番通し確認
- 実ユーザー2人によるログイン・DM・同行成立・評価テスト（`two-user-e2e.md` に確認済み範囲と残作業を記録）
- RLSとstudent-chat分離の最終確認
- 退会・データ削除の確認
- バックアップ・復元手順（手順書整備済み。2026-10-10 に初回バックアップを取得。Free プランのため復元演習は未実施）
- エラー監視と障害時の連絡方法（クライアントエラー収集を実装済み）

## P1：公開直後までに優先

- スマホ・主要ブラウザ確認
- 通報・ブロック・管理対応の運用ルール
- 実在アイドル・公演データの登録
- 公演情報の更新・中止対応
- 重複公演チェック
- 通知の停止・変更確認
- アクセシビリティ確認
- 投稿・DMの過剰利用対策
- Supabaseの漏洩パスワード保護
- 管理用SECURITY DEFINER警告の再確認

## P2：利用者を増やすために優先

- メール・ブラウザ通知
- フォロー通知の強化
- 参戦カレンダー
- 公演参加者検索
- プロフィール共有カード
- 人気公演・検索語の分析
- 公演情報の変更履歴
- 通報対応状況の表示

## P3：利用が増えてから

- 年間の推し活まとめ
- グループ別ファンコミュニティ
- 同行募集の再掲載
- 参加者一覧の高度化
- 人気ランキング
- 有料機能・広告
